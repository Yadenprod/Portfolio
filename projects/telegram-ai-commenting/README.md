## 📋 Описание проекта

Telegram Neuro Commenting System - это система автоматического комментирования в Telegram каналах с использованием QR-код авторизации. Система генерирует релевантные комментарии и автоматически публикует их в целевых каналах.

### 🎯 Основная концепция

Система автоматически:
1. Авторизуется через QR-код
2. Мониторит целевые каналы
3. Генерирует релевантные комментарии
4. Публикует комментарии с задержками
5. Отслеживает лимиты и статистику

## 🔧 Установка и запуск

### Требования

- Node.js 16+
- npm или yarn

### Установка

```bash

```

### Авторизация

```bash

```

### Запуск
