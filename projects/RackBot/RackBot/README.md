# RackBot для Radmir RP

Headless бот для автоматической регистрации, авторизации и прокачки аккаунтов на сервере Radmir RP без использования графического клиента.

## 🎯 Основные возможности

- ✅ **Headless работа** - работает полностью через консоль, без GUI
- ✅ **Автоматическая регистрация** аккаунтов на сервере
- ✅ **Автоматическая авторизация** аккаунтов
- ✅ **Автоматическая прокачка опыта** для каждого аккаунта
- ✅ **Уникальный IP для каждого аккаунта** через прокси
- ✅ **Подмена MAC адреса** для каждого аккаунта
- ✅ **Управление множеством аккаунтов** одновременно

## ⚠️ ВАЖНО

**Использование ботов может нарушать правила сервера Radmir RP и привести к бану аккаунтов. Используйте на свой риск!**

## 📋 Требования

- Python 3.8+
- Windows или Linux
- Права администратора (для изменения MAC адреса)
- Прокси серверы (для разных IP)
- **Moonloader и SAMPFUNCS** (для автоматизации через скрипты)
- Знание API/протокола Radmir RP для регистрации и авторизации (см. `API_DISCOVERY.md`)

## 🚀 Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Настройте конфигурацию в `config/config.json`

3. Добавьте прокси в `data/proxies.json` (создайте файл если его нет)

4. Запустите бота:
```bash
python src/bot.py
```

## ⚙️ Конфигурация

### Основные настройки (`config/config.json`):

```json
{
  "bot": {
    "max_accounts": 10,  // Максимум одновременных аккаунтов
    "check_interval_seconds": 60  // Интервал проверки
  },
  "server": {
    "ip": "127.0.0.1",  // IP сервера Radmir RP
    "port": 7777  // Порт сервера
  },
  "network": {
    "change_mac": true,  // Подменять MAC адрес
    "network_interface": "Ethernet",  // Имя сетевого интерфейса
    "mac_per_account": true  // Уникальный MAC для каждого аккаунта
  }
}
```

## 🔧 Использование

### Создание аккаунтов

```python
from src.bot import RackBot

bot = RackBot()
bot.create_accounts_batch(10)  # Создать 10 аккаунтов
```

### Добавление прокси

```python
from src.proxy_manager import ProxyManager

pm = ProxyManager()
pm.add_proxy(
    host="proxy.example.com",
    port=8080,
    username="user",
    password="pass",
    proxy_type="http"
)
```

### Работа бота

Бот автоматически:
1. Создает аккаунты (если настроено)
2. Регистрирует их на сервере
3. Подключается с уникальным IP (через прокси)
4. Подменяет MAC адрес
5. Авторизуется
6. Качает опыт автоматически

## 🔒 Безопасность

- Каждый аккаунт использует свой прокси (уникальный IP)
- Каждый аккаунт имеет уникальный MAC адрес
- Случайные задержки между действиями
- Имитация человеческого поведения
