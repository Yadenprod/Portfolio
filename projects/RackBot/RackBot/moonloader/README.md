# Скрипты для анализа протокола Radmir RP

Этот набор скриптов предназначен для детального изучения протокола сервера Radmir RP.

## 📋 Установка

1. Убедитесь, что установлены Moonloader и SAMPFUNCS
2. Скопируйте нужные скрипты в папку `moonloader/` вашей игры
3. Запустите игру и подключитесь к серверу Radmir RP

## 🔍 Доступные скрипты

### 1. `protocol_analyzer.lua` - Полный анализатор протокола
**Что делает:**
- Перехватывает все команды (отправляемые и получаемые)
- Логирует все сообщения сервера
- Сохраняет информацию о диалогах
- Записывает все события подключения/отключения

**Когда использовать:**
- Для общего изучения протокола
- Для анализа всех взаимодействий с сервером

**Результаты:**
- `protocol_logs/commands_sent.log` - отправленные команды
- `protocol_logs/server_messages.log` - сообщения сервера
- `protocol_logs/dialogs.log` - информация о диалогах
- `protocol_logs/chat.log` - сообщения чата
- JSON файлы с детальными данными

### 2. `registration_analyzer.lua` - Анализатор регистрации
**Что делает:**
- Специально отслеживает процесс регистрации
- Записывает все шаги регистрации
- Сохраняет диалоги регистрации
- Определяет успех/ошибку регистрации

**Когда использовать:**
- Когда выполняете регистрацию нового аккаунта
- Для изучения формата регистрации

**Как использовать:**
1. Запустите скрипт
2. В игре выполните процесс регистрации
3. Скрипт автоматически определит начало и конец регистрации
4. Проверьте `registration_logs/registration_report.txt`

**Результаты:**
- `registration_logs/registration_steps.log` - все шаги
- `registration_logs/registration_data.json` - полные данные
- `registration_logs/registration_report.txt` - итоговый отчет
- `registration_logs/dialog_*.txt` - тексты диалогов

### 3. `login_analyzer.lua` - Анализатор авторизации
**Что делает:**
- Отслеживает процесс входа в игру
- Записывает команды авторизации
- Сохраняет диалоги входа
- Определяет успех/ошибку авторизации

**Когда использовать:**
- Когда входите в игру
- Для изучения формата авторизации

**Результаты:**
- `login_logs/login_steps.log` - все шаги
- `login_logs/login_data.json` - полные данные
- `login_logs/login_report.txt` - итоговый отчет

### 4. `network_packet_logger.lua` - Логгер пакетов
**Что делает:**
- Перехватывает сетевые пакеты (если доступно)
- Логирует ID пакетов
- Записывает время отправки/получения

**Когда использовать:**
- Для глубокого анализа сетевого протокола
- Если нужно изучить структуру пакетов

**Примечание:** Требует расширенных возможностей SAMPFUNCS

## 📝 Инструкция по использованию

### Шаг 1: Регистрация
1. Запустите `registration_analyzer.lua`
2. В игре выполните регистрацию нового аккаунта
3. Дождитесь завершения процесса
4. Проверьте логи в `moonloader/registration_logs/`

### Шаг 2: Авторизация
1. Запустите `login_analyzer.lua`
2. Войдите в игру с зарегистрированным аккаунтом
3. Проверьте логи в `moonloader/login_logs/`

### Шаг 3: Общий анализ
1. Запустите `protocol_analyzer.lua`
2. Выполните различные действия в игре
3. Проверьте логи в `moonloader/protocol_logs/`

## 📊 Что искать в логах

### Для регистрации:
- Команда регистрации (формат: `/register ...`)
- ID диалога регистрации
- Поля диалога (что нужно ввести)
- Сообщения об успехе/ошибке

### Для авторизации:
- Команда входа (формат: `/login ...`)
- ID диалога авторизации
- Формат пароля
- Сообщения об успехе/ошибке

### Для прокачки:
- Команды для получения опыта
- Сообщения о получении опыта
- Ограничения по времени/действиям

## 🔄 После сбора данных

1. Соберите все логи из папок:
   - `protocol_logs/`
   - `registration_logs/`
   - `login_logs/`
   - `packet_logs/` (если использовали)

2. Отправьте данные разработчику бота

3. Разработчик обновит код с найденным протоколом

## ⚠️ Важно

- Запускайте скрипты по одному (не все сразу)
- Выполняйте действия медленно для точного логирования
- Сохраняйте все логи для анализа
- Не удаляйте JSON файлы - они содержат структурированные данные

## 💡 Советы

1. **Начните с регистрации** - это самый важный процесс
2. **Повторите процесс несколько раз** - для проверки стабильности
3. **Обратите внимание на диалоги** - они содержат важную информацию
4. **Проверяйте сообщения сервера** - там могут быть подсказки о формате
