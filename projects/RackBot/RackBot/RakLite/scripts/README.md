# Скрипты для RakLite

## 📁 Структура

```
scripts/
├── register.lua    # Регистрация аккаунта
├── login.lua       # Авторизация
├── farm.lua        # Прокачка опыта
└── libs/           # Библиотеки (не трогать!)
```

## 🚀 Использование

1. **Откройте нужный скрипт** (register.lua, login.lua, farm.lua)
2. **Измените настройки** в начале файла:
   - `username` - имя пользователя
   - `password` - пароль
   - `email` - email (для регистрации)
3. **Запустите RakLite** - скрипт загрузится автоматически

## 📝 Скрипты

### register.lua
- Регистрирует новый аккаунт
- Обрабатывает диалоги регистрации
- Сохраняет результат в `results/register_*.json`

### login.lua
- Авторизуется на сервере
- Обрабатывает диалоги авторизации
- Сохраняет результат в `results/login_*.json`

### farm.lua
- Прокачивает опыт
- Удерживает W 5 сек → пауза 20 сек → S 5 сек → пауза 20 сек
- Повторяет бесконечно

## ⚙️ Настройка

Откройте скрипт и измените переменные в начале:

```lua
local username = "ваше_имя"
local password = "ваш_пароль"
local email = "ваш@email.com"
```

## 📊 Результаты

Результаты сохраняются в папке `results/`:
- `register_username.json` - результат регистрации
- `login_username.json` - результат авторизации
