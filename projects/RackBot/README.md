## 📋 Описание проекта

RackBot - это headless бот для автоматической регистрации, авторизации и прокачки аккаунтов на сервере Radmir RP без использования графического клиента. Система работает полностью через консоль и использует Moonloader для автоматизации игровых действий.

### 🎯 Основная концепция

Бот автоматически:
1. Регистрирует аккаунты на сервере
2. Авторизуется с уникальным IP через прокси
3. Подменяет MAC адрес для каждого аккаунта
4. Прокачивает опыт через Moonloader скрипты
5. Управляет множеством аккаунтов одновременно

## 🏗️ Архитектура

### Основные компоненты

#### 1. **Bot Core** (`src/bot.py`)
- Главный модуль бота
- Управление жизненным циклом аккаунтов
- Координация всех компонентов

#### 2. **Account Manager** (`src/account_manager.py`)
- Создание и управление аккаунтами
- Хранение данных аккаунтов
- Отслеживание статуса

#### 3. **Proxy Manager** (`src/proxy_manager.py`)
- Управление прокси серверами
- Ротация прокси
- Проверка доступности

#### 4. **MAC Changer** (`src/mac_changer.py`)
- Подмена MAC адреса
- Уникальный MAC для каждого аккаунта
- Восстановление оригинального MAC

#### 5. **SAMP Client** (`src/samp_client.py`)
- Headless подключение к SAMP серверу
- Обработка протокола SAMP
- Управление соединением

#### 6. **Moonloader Integration**
- Генерация скриптов для автоматизации
- Интеграция с Moonloader
- Выполнение игровых действий

## 🔧 Установка и запуск

### Требования

- Python 3.8+
- Windows или Linux
- Права администратора (для изменения MAC)
- Прокси серверы
- Moonloader и SAMPFUNCS

### Установка

```bash
pip install -r requirements.txt
```

### Конфигурация

Настройте `config/config.json`:

```json
{
  "bot": {
    "max_accounts": 10,
    "check_interval_seconds": 60
  },
  "server": {
    "ip": "127.0.0.1",
    "port": 7777
  },
  "network": {
    "change_mac": true,
    "network_interface": "Ethernet",
    "mac_per_account": true
  }
}
```

### Запуск

```bash
python src/bot.py
```
