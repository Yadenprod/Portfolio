=============================================
= ИНСТРУКЦИЯ ПО УСТАНОВКЕ MOBILE LEGENDS CASES =
=============================================

ТРЕБОВАНИЯ:
- Windows 10 или выше
- Права администратора для настройки hosts файла
- Минимум 1 ГБ свободного места на диске

ШАГ 1: УСТАНОВКА XAMPP
---------------------
1. Скачайте XAMPP с официального сайта: https://www.apachefriends.org/download.html
   (рекомендуется версия для PHP 8.2.12)
2. Запустите скачанный установщик и следуйте инструкциям:
   - Выберите компоненты: Apache, MySQL, PHP, phpMyAdmin
   - Установите XAMPP в директорию D:\XPL
3. После установки НЕ запускайте XAMPP Control Panel

ШАГ 2: ЗАПУСК СКРИПТА НАСТРОЙКИ
-----------------------------
1. После установки XAMPP запустите файл setup_mobile_legends.bat
   - Щелкните правой кнопкой мыши и выберите "Запустить от имени администратора"
2. Следуйте инструкциям на экране:
   - Скрипт настроит виртуальный хост Apache
   - Создаст необходимую базу данных
   - Импортирует структуру базы данных
   - Запустит XAMPP Control Panel

ШАГ 3: НАСТРОЙКА HOSTS ФАЙЛА
--------------------------
1. Откройте блокнот от имени администратора
2. Откройте файл: C:\Windows\System32\drivers\etc\hosts
3. Добавьте в конец файла:
   127.0.0.1 mobile-legends.local
4. Сохраните файл

ШАГ 4: ЗАПУСК СЕРВЕРОВ
--------------------
1. В XAMPP Control Panel запустите:
   - Apache
   - MySQL
2. Откройте браузер и перейдите по адресу:
   http://mobile-legends.local/install.php
3. После успешной установки удалите файл install.php

ШАГ 5: ДОСТУП К САЙТУ
------------------
1. Перейдите по адресу: http://mobile-legends.local/
2. Для доступа к админ-панели: http://mobile-legends.local/admin/
   - Логин: admin
   - Пароль: 12345

УСТРАНЕНИЕ НЕПОЛАДОК:
-------------------
1. Ошибка "Could not connect to MySQL": 
   - Убедитесь, что MySQL запущен в XAMPP Control Panel
   - Проверьте настройки в файле html/core/settings/DataBaseSet.php

2. Ошибка 404 / Not Found:
   - Убедитесь, что Apache запущен в XAMPP Control Panel
   - Проверьте настройки виртуального хоста
   - Проверьте, что hosts файл правильно настроен

3. Ошибка доступа к файлам:
   - Убедитесь, что у Apache есть права на чтение файлов
   - Перезапустите Apache
