============================
MOBILE LEGENDS CASES
============================

БЫСТРЫЙ ЗАПУСК:
1. Установите XAMPP с сайта: https://www.apachefriends.org/download.html
   и установите в директорию D:\XPL
2. Запустите скрипт setup_mobile_legends.bat от имени администратора
3. Настройте hosts файл (C:\Windows\System32\drivers\etc\hosts):
   127.0.0.1 mobile-legends.local
4. Запустите Apache и MySQL в XAMPP Control Panel
5. Откройте сайт: http://mobile-legends.local/install.php
6. После установки откройте: http://mobile-legends.local/

Админ-панель: http://mobile-legends.local/admin/
Логин: admin
Пароль: 12345

Полная инструкция находится в файле ИНСТРУКЦИЯ_УСТАНОВКИ.txt
