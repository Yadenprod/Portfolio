# AI Triggerbot (Python + Go)

## Описание

В этой папке реализован интеллектуальный триггербот для игр (например, Valorant), который использует нейросеть для распознавания врагов на экране. Основная логика:
- Go-программа захватывает область экрана и отправляет её Python-скрипту.
- Python-скрипт с помощью нейросети (YOLOv5/YOLOv8) определяет наличие врага.
- Если враг найден — Go-программа эмулирует нажатие (или удержание) нужной кнопки.

## Структура
- `go_client.go` — клиент на Go, захват экрана, отправка в Python, эмуляция нажатий.
- `py_server.py` — сервер на Python, принимает изображения, запускает нейросеть, возвращает результат.
- `model/` — папка для модели нейросети (YOLOv5/YOLOv8 .pt или .onnx).
- `README.md` — эта инструкция.

## Требования
- Go 1.18+
- Python 3.8+
- Библиотеки: `ultralytics`, `opencv-python`, `numpy`, `flask` (или FastAPI)

## Как работает
1. Запусти `py_server.py` (сервер с нейросетью).
2. Запусти `go_client.go` (клиент, который захватывает экран и отправляет картинки).
3. Если сервер вернул "есть враг" — Go-клиент эмулирует нажатие.

## Настройка модели
- Модель YOLOv5/YOLOv8 можно обучить на своих скриншотах (см. инструкции в репозитории ultralytics/yolov5).
- Помести файл модели в папку `model/` и укажи путь в `py_server.py`.
