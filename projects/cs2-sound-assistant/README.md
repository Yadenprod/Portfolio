## 📋 Описание проекта

CS2 Sound Assistant - это инновационная система, которая анализирует звуки игры Counter-Strike 2 для определения точного местоположения противников. Система работает в режиме реального времени и отображает позиции на радаре.

### 🎯 Основная концепция

Система автоматически:
1. Захватывает системное аудио игры
2. Анализирует звуки (шаги, выстрелы, взрывы, голоса)
3. Определяет направление источника звука
4. Рассчитывает расстояние до источника
5. Отображает позиции на визуальном радаре

## 🏗️ Архитектура

### Основные компоненты

#### 1. **Audio Capture** (`src/audio/capture.py`)
- **Системный захват:** Захват аудио через PyAudio с настраиваемым sample_rate (48000 Hz)
- **Буферизация:** Chunk-based обработка (1024 samples) для real-time анализа
- **Многопоточность:** Отдельный поток для захвата без блокировки основного потока

#### 2. **Sound Analyzer** (`src/analysis/analyzer.py`)
- **FFT анализ:** Fast Fourier Transform для частотного анализа через `scipy.fft`
- **Butterworth фильтры:**
  - Lowpass 8kHz для шумов
  - Highpass 300Hz для голоса
  - Bandpass 100-2000Hz для шагов
- **Частотные диапазоны:**
  - **Footsteps:** 100-1000Hz, длительность 0.1-0.5s, amplitude threshold 0.1
  - **Gunshot:** 1000-5000Hz, длительность 0.05-0.2s, amplitude threshold 0.2
  - **Explosion:** 50-2000Hz, длительность 0.2-1.0s, amplitude threshold 0.3
  - **Voice:** 200-3000Hz, длительность 0.1-2.0s, amplitude threshold 0.15
- **RMS амплитуда:** Проверка уровня сигнала для фильтрации тишины

#### 3. **Position Calculator** (`src/positioning/calculator.py`)
- **ITD/ILD расчеты:**
  - **ITD (Interaural Time Difference):** Разница времени прихода звука к ушам
  - **ILD (Interaural Level Difference):** Разница амплитуды между каналами
- **Физические параметры:**
  - Расстояние между ушами: 0.15м (15см)
  - Скорость звука: 343 м/с
  - Максимальная дистанция: 50м
- **Калибровка:** Применение калибровочных данных для точности
- **Confidence calculation:** Расчет уверенности позиции на основе корреляции

#### 4. **Visual Radar**
- Overlay радар
- Отображение противников
- Обновление в реальном времени

#### 5. **Calibration**
- Калибровка акустической системы
- Настройка чувствительности
- Тестирование
