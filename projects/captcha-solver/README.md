## 📋 Описание проекта

Captcha Solver - это продвинутая система распознавания капчи, которая использует комбинацию собственных ML моделей (CNN+LSTM) и множественных OCR движков (PaddleOCR, EasyOCR, ddddocr) для достижения максимальной точности распознавания.

### 🎯 Основная концепция

Система использует 4 подхода одновременно:
1. **Собственная CNN+LSTM модель** - Для последовательного распознавания символов
2. **PaddleOCR** - Продвинутый OCR движок
3. **EasyOCR** - Легковесный OCR
4. **ddddocr** - Специализированный решатель капчи

Результаты комбинируются для максимальной точности.

## 🏗️ Архитектура

### Основные компоненты

#### 1. **CaptchaSolver** (`captcha_solver/solver.py`)
- Главный класс решателя
- Координация всех методов
- Комбинирование результатов
- Статистика производительности

**Методы распознавания:**
- `solve_with_cnn_lstm()` - CNN+LSTM модель
- `solve_with_paddleocr()` - PaddleOCR
- `solve_with_easyocr()` - EasyOCR
- `solve_with_ddddocr()` - ddddocr
- `solve_ensemble()` - Комбинирование всех методов

#### 2. **CaptchaPreprocessor** (`captcha_solver/preprocessor.py`)
- Предобработка изображений
- Удаление шума и артефактов
- Обработка капчи с сеткой
- Улучшение контраста
- Морфологические операции

**Методы обработки:**
- `preprocess()` - Основная обработка
- `preprocess_grid_captcha_gentle()` - Мягкая обработка сетки
- `remove_grid_lines()` - Удаление линий сетки
- `enhance_text()` - Улучшение текста
- `denoise()` - Удаление шума

#### 3. **CaptchaModel** (`captcha_solver/models.py`)
- CNN+LSTM модель для распознавания
- Классификатор отдельных символов
- Обучение и инференс
- Сохранение/загрузка моделей

**Архитектура CNN+LSTM:**
- 4 слоя Conv2D (32, 64, 128, 256 фильтров)
- BatchNormalization
- MaxPooling2D
- Bidirectional LSTM (256, 128)
- Dense слои для классификации

**Архитектура Character Classifier:**
- 3 слоя Conv2D (32, 64, 128 фильтров)
- Global Average Pooling
- Dense слои

## 🔧 Установка и запуск

### Требования

- Python 3.8+
- TensorFlow (опционально, для CNN+LSTM)
- OpenCV
- PaddleOCR, EasyOCR, ddddocr

### Установка

```bash
pip install -r requirements.txt
```

### Использование

```python
from captcha_solver.solver import CaptchaSolver

solver = CaptchaSolver()
result = solver.solve("captcha_image.png")
print(f"Распознано: {result['text']}, уверенность: {result['confidence']}")
```
