## 📋 Описание проекта

CarCheckPro - это мобильное приложение, которое помогает покупателям автомобилей проверить машину перед покупкой. Приложение предоставляет детальную информацию о типичных проблемах конкретных моделей автомобилей, интерактивные чек-листы для осмотра и возможность сохранения отчетов с фотографиями.

### 🎯 Основная концепция

Пользователь выбирает марку и модель автомобиля, после чего получает:
- Список типичных проблем для данной модели
- Детальный чек-лист для проверки
- Возможность сохранения отчета с фотографиями
- Рекомендации по осмотру

## 🏗️ Архитектура

### Технологический стек

- **React Native** - Кросс-платформенная разработка
- **Expo** - Упрощенная разработка и деплой
- **TypeScript** - Типобезопасность
- **React Navigation** - Навигация между экранами
- **React Native Paper** - Material Design компоненты

### Структура приложения

#### **Экраны (Screens):**

1. **HomeScreen** - Главный экран
   - Приветствие и описание функционала
   - Кнопка "Начать проверку"
   - Инструкция "Как это работает"

2. **CarSearchScreen** - Поиск автомобиля
   - Поиск по марке автомобиля
   - Список популярных марок (Toyota, Honda, BMW, Mercedes-Benz, Audi, Volkswagen, Ford, Chevrolet)
   - Выбор модели после выбора марки
   - Навигация к деталям автомобиля

3. **CarDetailsScreen** - Детали автомобиля
   - Отображение типичных проблем по категориям:
     - Двигатель (маслосъемные колпачки, течь масла, гидрокомпенсаторы)
     - Трансмиссия (износ сцепления, синхронизаторы, течь масла)
     - Подвеска (шаровые опоры, сайлентблоки, амортизаторы)
   - Чек-лист для осмотра:
     - Внешний осмотр (ржавчина, ЛКП, стекла)
     - Проверка двигателя (масло, течи, работа на холодную)
     - Проверка ходовой (люфты, шины, тормоза)
   - Кнопка "Сохранить отчет"

#### **Навигация:**

- Stack Navigator для перехода между экранами
- Параметры маршрутизации (brand, model)
- Обработка навигации через React Navigation hooks

#### **UI Компоненты:**

- **Card** - Карточки для отображения информации
- **Button** - Кнопки действий
- **Text** - Текстовые элементы с вариантами (headlineMedium, titleLarge, bodyLarge)
- **List.Item** - Элементы списка с иконками
- **TextInput** - Поле поиска
- **Divider** - Разделители между секциями

## 🚀 Установка и запуск

### Требования

- Node.js 16+
- npm или yarn
- Expo CLI
- iOS Simulator (для iOS) или Android Emulator (для Android)

### Установка

```bash
npm install
# или
yarn install
```

### Запуск

```bash
# Запуск на iOS
npm run ios

# Запуск на Android
npm run android

# Запуск в веб-браузере
npm run web

# Запуск Expo Dev Server
npm start
```
