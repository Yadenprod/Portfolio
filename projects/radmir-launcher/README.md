## 📋 Описание проекта

RADMIR Multi-Account Launcher - это система автоматизации для запуска множества аккаунтов RADMIR через Sandboxie с автоматическим изменением системного времени. Система поддерживает до 20 одновременных аккаунтов и полностью автоматизирует процесс запуска.

### 🎯 Основная концепция

Система автоматически:
1. Изменяет системное время на указанное количество лет назад
2. Запускает лаунчер RADMIR в песочнице Sandboxie
3. Обрабатывает диалоги UAC и новые лаунчеры
4. Выбирает сервер и вводит никнейм
5. Вводит пароль в игре
6. Переходит к следующему аккаунту

## 🔧 Установка и запуск

### Требования

- Windows 10/11
- Python 3.8+
- Sandboxie-Plus
- Права администратора
- RADMIR Launcher

### Установка

```bash
pip install -r requirements.txt
```

### Настройка Sandboxie

1. Создайте 20 песочниц: `okno1`, `okno2`, ..., `okno20`
2. Настройте изоляцию по своему усмотрению

### Конфигурация

Настройте `config.json`:

```json
{
  "launcher_path": "C:\\Program Files (x86)\\Radic\\RADMIR LAUNCHER\\RADMIR_LAUNCHER_EX.exe",
  "sandboxie_start": "C:\\Program Files\\Sandboxie-Plus\\Start.exe",
  "common_password": "ваш_общий_пароль",
  "time_shift_years": 1,
  "accounts": [
    {
      "sandbox": "okno1",
      "nickname": "Player1",
      "server": "SERVER 1"
    }
  ]
}
```

### Запуск

**ВАЖНО: Запускайте с правами администратора!**

```bash
python main.py
```

## 🔒 Безопасность

⚠️ **Важные предупреждения:**

- Скрипт изменяет системное время - используйте на свой риск
- Требует прав администратора - проверяйте код перед запуском
- Пароли хранятся в открытом виде в `config.json` - не делитесь этим файлом
- После завершения работы верните системное время вручную

## 🛠️ Решение проблем

### Ошибка: "Требуются права администратора"
**Решение:** Запускайте скрипт от имени администратора

### Ошибка: "Не удалось изменить системное время"
**Решение:** Отключите синхронизацию времени с интернетом

### Ошибка: "Окно не найдено"
**Решение:** Увеличьте таймауты в коде
