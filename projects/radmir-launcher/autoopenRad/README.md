# RADMIR Multi-Account Launcher

Автоматизация запуска множества аккаунтов RADMIR через Sandboxie с автоматическим изменением системного времени.

## 🎯 Возможности

- ✅ Автоматический запуск лаунчера RADMIR в песочницах Sandboxie
- ✅ Запуск с правами администратора (UAC)
- ✅ Автоматическое изменение системного времени
- ✅ Автоматический выбор сервера и ввод никнейма
- ✅ Автоматический ввод пароля в игре
- ✅ Поддержка до 20 песочниц одновременно
- ✅ Подробное логирование всех действий
- ✅ Обработка ошибок и автоматическое восстановление

## 📋 Требования

### Системные требования
- Windows 10/11
- Python 3.8 или выше
- Sandboxie-Plus (установленный и настроенный)
- Права администратора

### Программное обеспечение
1. **Python** - [скачать](https://www.python.org/downloads/)
2. **Sandboxie-Plus** - [скачать](https://github.com/sandboxie-plus/Sandboxie/releases)
3. **RADMIR Launcher** - должен быть установлен

## 🚀 Установка

### Шаг 1: Клонирование/Скачивание проекта
```bash
cd E:\autoopenRad
```

### Шаг 2: Установка зависимостей
```bash
pip install -r requirements.txt
```

### Шаг 3: Настройка Sandboxie

1. Откройте Sandboxie-Plus
2. Создайте 20 песочниц с названиями: `okno1`, `okno2`, `okno3`, ..., `okno20`
3. Для каждой песочницы рекомендуется:
   - Включить "Auto Delete" при закрытии (опционально)
   - Настроить изоляцию по своему усмотрению

### Шаг 4: Настройка конфигурации

Отредактируйте файл `config.json`:

```json
{
  "launcher_path": "C:\\Program Files (x86)\\Radic\\RADMIR LAUNCHER\\RADMIR_LAUNCHER_EX.exe",
  "sandboxie_start": "C:\\Program Files\\Sandboxie-Plus\\Start.exe",
  "common_password": "ваш_общий_пароль",
  "time_shift_years": 1,
  "accounts": [
    {
      "sandbox": "okno1",
      "nickname": "Player1",
      "server": "SERVER 1"
    },
    ...
  ]
}
```

#### Параметры конфигурации:

- **launcher_path** - путь к RADMIR_LAUNCHER_EX.exe
- **sandboxie_start** - путь к Start.exe из Sandboxie
- **common_password** - общий пароль для всех аккаунтов
- **time_shift_years** - на сколько лет сдвигать время назад
- **accounts** - список аккаунтов:
  - `sandbox` - название песочницы (okno1, okno2, и т.д.)
  - `nickname` - никнейм игрока
  - `server` - название сервера (должно совпадать с текстом в лаунчере)

### Шаг 5: Заполнение списка аккаунтов

В файле `Аккаунты.txt` вы можете хранить информацию об аккаунтах в любом удобном формате.
Основная конфигурация берется из `config.json`.

## 🎮 Использование

### ВАЖНО: Запуск с правами администратора

Программа **обязательно** должна запускаться с правами администратора для изменения системного времени!

#### Способ 1: Через командную строку (рекомендуется)
1. Откройте командную строку **от имени администратора**
2. Перейдите в папку проекта:
   ```bash
   cd E:\autoopenRad
   ```
3. Запустите:
   ```bash
   python main.py
   ```

#### Способ 2: Через bat-файл (создайте)
Создайте файл `run_as_admin.bat`:
```batch
@echo off
cd /d "%~dp0"
python main.py
pause
```
Запускайте этот файл **от имени администратора**.

### Режимы работы

При запуске программа предложит выбрать режим:

1. **Запустить все аккаунты** - обработает все 20 аккаунтов по очереди
2. **Запустить определенный диапазон** - например, аккаунты с 5 по 10
3. **Запустить один аккаунт** - для тестирования или единичного запуска

### Процесс работы

Для каждого аккаунта программа выполняет:

1. ⏰ Изменяет системное время на 1 год назад
2. 📦 Запускает лаунчер в песочнице с UAC
3. ✅ Нажимает "Yes" в диалоге Sandboxie UAC
4. ❌ Закрывает диалог "Новый лаунчер"
5. 🎯 Выбирает сервер
6. 👤 Вводит никнейм
7. ▶️ Нажимает "Играть"
8. 🔑 Вводит пароль в игре
9. ♻️ Переходит к следующему аккаунту

## 🛠️ Решение проблем

### Ошибка: "Требуются права администратора"
**Решение:** Запускайте скрипт от имени администратора (см. раздел "Использование")

### Ошибка: "Не удалось изменить системное время"
**Причины:**
- Недостаточно прав (нужен администратор)
- Время синхронизируется с интернетом

**Решение:**
1. Отключите синхронизацию времени:
   - Панель управления → Дата и время → Время по интернету
   - Снимите галочку "Синхронизировать с сервером времени в Интернете"

### Ошибка: "Окно не найдено"
**Причины:**
- Окно открывается медленно
- Неверный заголовок окна

**Решение:**
- Увеличьте таймауты в коде (параметр `timeout` в методах)
- Проверьте, что окна действительно открываются

### Кнопки не нажимаются
**Причины:**
- Интерфейс изменился
- Неверные идентификаторы элементов

**Решение:**
- Используйте инструмент Inspect.exe (из Windows SDK) для анализа структуры окон
- Обновите код с правильными идентификаторами
