🚀 БЫСТРЫЙ СТАРТ (3 МИНУТЫ)
═══════════════════════════════════════════════════════════════════════════

Шаг 1: Установите зависимости
    cmd> pip install -r requirements.txt

Шаг 2: Проверьте окружение
    cmd> python check_environment.py

Шаг 3: Настройте config.json
    - Откройте config.json в блокноте
    - Измените "common_password" на ваш пароль
    - Добавьте ваши аккаунты (или используйте python update_accounts.py)

Шаг 4: Запустите!
    - ПКМ на run_as_admin.bat → "Запуск от имени администратора"

⚡ САМАЯ ВАЖНАЯ ИНФОРМАЦИЯ
═══════════════════════════════════════════════════════════════════════════

1. ВСЕГДА ЗАПУСКАЙТЕ ОТ ИМЕНИ АДМИНИСТРАТОРА
   (Для изменения системного времени)

2. ОТКЛЮЧИТЕ СИНХРОНИЗАЦИЮ ВРЕМЕНИ
   Параметры → Время и язык → Дата и время
   Отключить: "Установить время автоматически"

3. СОЗДАЙТЕ 20 ПЕСОЧНИЦ В SANDBOXIE
   Имена: okno1, okno2, okno3, ..., okno20
   Автоматически: PowerShell > .\create_sandboxes.ps1

4. НАСТРОЙТЕ config.json
   Укажите: пути, пароль, список аккаунтов

5. СНАЧАЛА ТЕСТИРУЙТЕ НА ОДНОМ АККАУНТЕ
   python test_single_account.py

6. ВОССТАНАВЛИВАЙТЕ ВРЕМЯ ПОСЛЕ РАБОТЫ
   python restore_time.py
