## 📋 Описание проекта

GTA RP AI Assistant - это полноценный автономный AI-ассистент для игры GTA RP, который может работать полностью самостоятельно, принимая решения на основе анализа экрана, обучаясь на опыте и адаптируя свое поведение. Система использует Computer Vision, Reinforcement Learning и State Machine для создания реалистичного игрового поведения.

### 🎯 Основная концепция

AI автоматически:
1. Анализирует экран игры с помощью Computer Vision
2. Принимает решения на основе состояния игры
3. Управляет персонажем через эмуляцию клавиатуры и мыши
4. Обучается на опыте и улучшает свои действия
5. Адаптирует поведение для более естественной игры
6. Работает в различных режимах (работа, исследование, отдых)

## 🏗️ Архитектура

### Основные модули (15 компонентов)

#### 1. **Main Controller** (`main.py`)
- Главный класс `GTA_RP_AI`
- Координация всех систем
- Основной цикл обработки кадров
- Управление жизненным циклом AI

#### 2. **Screen Capture** (`screen_capture.py`)
- Захват экрана игры
- Оптимизация производительности
- Обработка кадров

#### 3. **Vision Processor** (`vision.py`)
- Обработка визуальной информации
- Распознавание текста (Tesseract OCR)
- Детекция объектов и цветов
- Анализ интерфейса игры

#### 4. **Decision Maker** (`decision_maker.py`)
- Принятие решений на основе состояния
- 10 типов действий (MOVE_FORWARD, TURN_LEFT, INTERACT, ATTACK, и т.д.)
- Анализ состояния игры
- Обработка текста для принятия решений

#### 5. **State Machine** (`state_machine.py`)
- Управление состояниями игры
- 9 состояний (IDLE, WALKING, DRIVING, WORKING, SHOPPING, SOCIALIZING, EXPLORING, RESTING, EMERGENCY)
- Правила переходов между состояниями
- Обработчики состояний

#### 6. **Navigation System** (`navigation.py`)
- Навигация по карте
- Извлечение данных из мини-карты
- Поиск маркеров игрока и целей
- Расчет маршрутов

#### 7. **Work System** (`work_system.py`)
- Управление работой
- 6 типов работы (DELIVERY, TAXI, TRUCKER, MINER, FISHER, MECHANIC)
- Детекция возможностей работы
- Отслеживание заработка

#### 8. **Human Behavior Simulator** (`human_behavior.py`)
- Имитация человеческого поведения
- Случайные задержки и ошибки
- Микропаузы между действиями
- Дрожание мыши для реалистичности
- Задержки при вводе текста

#### 9. **Learning System** (`learning_system.py`)
- Система самообучения
- `ExperienceMemory` - память опыта (до 10,000 записей)
- `LearningSystem` - обучение на основе опыта
- Расчет наград за действия
- Адаптация поведения

#### 10. **Auto Recovery** (`auto_recovery.py`)
- Автоматическое восстановление при ошибках
- Обработка критических ситуаций
- Восстановление состояния

#### 11. **Success Detector** (`success_detector.py`)
- Детекция успешных действий
- Анализ результатов
- Обратная связь для обучения

#### 12. **World Navigation** (`world_navigation.py`)
- Навигация по открытому миру
- Работа с картой
- Поиск точек интереса

#### 13. **Autonomous Life** (`autonomous_life.py`)
- Автономная жизнь AI
- Планирование действий
- Управление распорядком дня

#### 14. **Game Controller** (`controller.py`)
- Управление игрой
- Эмуляция клавиатуры и мыши
- Выполнение действий

#### 15. **Documentation**
- `FEATURES.md` - Описание возможностей
- `LEARNING.md` - Документация по обучению
- `HOW_IT_WORKS.md` - Как работает система
- `QUICKSTART.md` - Быстрый старт

## 🔧 Установка и запуск

### Требования

- Python 3.8+
- OpenCV
- Tesseract OCR
- NumPy
- keyboard, pyautogui

### Установка

```bash
pip install -r requirements.txt
```

### Запуск

```bash
python src/main.py
```

### Управление

- **F9** - Запуск/остановка AI
- **F10** - Выход из программы
- **F11** - Показать статистику
