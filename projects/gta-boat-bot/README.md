## 📋 Описание проекта

Boat Bot - это автоматизированный бот для игры GTA, который управляет лодкой и автоматически плывет к красным квадратам (целям) на миникарте. Бот использует Computer Vision для анализа миникарты и автоматического управления лодкой.

### 🎯 Основная концепция

Бот автоматически:
1. Захватывает область миникарты
2. Обнаруживает стрелочку игрока
3. Находит красные квадраты с черной оконтовкой (цели)
4. Вычисляет направление движения
5. Управляет лодкой клавишами W, A, D
6. Останавливается при достижении цели

## 🏗️ Архитектура

### Основные компоненты

#### 1. **State Machine** (`Bot/boat_bot_modules/state_machine.py`)
- **Управление состояниями:** Переходы между состояниями (IDLE, SEARCHING, NAVIGATING, ARRIVED)
- **Event-driven:** Обработка событий для плавных переходов
- **State validation:** Проверка валидности переходов

#### 2. **Object Detector** (`Bot/boat_bot_modules/detector.py`)
- **HSV кэширование:** Кэш HSV изображения для оптимизации (проверка hash первой строки)
- **Многоцветная детекция:** Поддержка 7+ цветов (red, green, yellow, pink, white, orange, purple)
- **Оптимизированный поиск:** Быстрая проверка наличия цвета перед полным поиском
- **DetectionResult dataclass:** Структурированный результат с center, contour, area, color, type
- **Специальная обработка красного:** Два HSV диапазона для красного (0-10 и 170-180)
- **Фильтрация по площади:** Минимальная площадь для исключения шума

#### 3. **Main Bot** (`Bot/boat_bot.py` - **3984 строки кода!**)
- **Низкоуровневое управление:** Windows API через `ctypes` и `SendInput` для надежной эмуляции
- **Глобальные хоткеи:** Низкоуровневый хук клавиатуры через `WH_KEYBOARD_LL` для паузы (F10)
- **Многопоточность:** Отдельные потоки для захвата экрана, детекции и управления
- **Checkpoint Counter:** Система подсчета пройденных чекпоинтов
- **Навигация:** Расчет углов и расстояний для точного движения к целям
- **Обработка ошибок:** Автоматическое восстановление после ошибок

#### 4. **Navigation System**
- Расчет направления движения
- Управление поворотами
- Достижение целей

## 🔧 Установка и запуск

### Требования

- Python 3.8+
- Windows (тестировалось на Windows 10/11)
- Игра должна быть запущена

### Установка

```bash
pip install -r requirements.txt
```

```bash
python calibrate.py
```

```bash
python Bot/boat_bot.py
```
