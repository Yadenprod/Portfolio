# Бот для автоматического плавания на лодке в GTA

Автоматизированный бот, который управляет лодкой в игре GTA и плывет к красным квадратам на миникарте.

## Возможности

- ✅ Автоматическое обнаружение стрелочки игрока на миникарте
- ✅ Обнаружение красных квадратов с черной оконтовкой (цели)
- ✅ Автоматическое вычисление направления движения
- ✅ Управление лодкой клавишами W, A, D
- ✅ Остановка при достижении цели
- ✅ Глобальный хоткей F10 для паузы/возобновления (работает в игре)
- ✅ Подробное логирование всех действий

## Требования

- Python 3.8 или выше (рекомендуется Python 3.10+)
- Windows (тестировалось на Windows 10/11)
- Игра должна быть запущена (оконный или полноэкранный режим)
- Окно игры должно быть видимым на экране
- **Для работы F10 (глобальный хоткей):** может потребоваться запуск от имени администратора

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

**Примечание:** Если у вас Python 3.12+, зависимости будут автоматически обновлены до совместимых версий.

## Настройка

### Шаг 1: Калибровка координат миникарты

Перед первым использованием необходимо определить координаты миникарты:

```bash
python calibrate.py
```

Эта утилита поможет вам:
1. Автоматически найдет окно игры "RADMIR CRMP" (или другое, указанное в config.py)
2. Позволит выбрать область миникарты на скриншоте окна игры
3. Автоматически определит координаты относительно окна игры
4. Протестировать захват области

**Важно:** Координаты миникарты теперь указываются относительно окна игры, а не всего экрана. Это позволяет боту работать даже если окно игры перемещено.

### Шаг 2: Настройка конфигурации

Откройте файл `config.py` и настройте параметры:

- `MINIMAP_REGION` - координаты области миникарты
- `MINIMAP_CENTER` - центр миникарты
- `TURN_THRESHOLD` - порог угла для поворота (в градусах)
- `MIN_DISTANCE` - минимальное расстояние до цели для остановки

Или скопируйте значения из `minimap_config.py` (если использовали калибровку).

## Использование

1. Запустите игру GTA
2. Сядьте на лодку
3. Убедитесь, что на миникарте виден красный квадрат (цель)
4. Запустите бота:

```bash
python boat_bot.py
```

5. Для остановки бота нажмите клавишу `q`

## Как это работает

1. **Захват миникарты**: Бот захватывает область экрана, где находится миникарта
2. **Обнаружение игрока**: Находит стрелочку игрока (черный треугольник с красным носиком и зеленой линией) в центре миникарты
3. **Обнаружение цели**: Находит красный квадрат с черной оконтовкой на миникарте
4. **Вычисление направления**: Вычисляет угол от игрока к цели
5. **Управление**: Нажимает клавиши W (движение), A (влево) или D (вправо) для движения к цели

## Устранение неполадок

### Бот не находит стрелочку игрока

- Убедитесь, что координаты миникарты настроены правильно
- Проверьте, что миникарта видна на экране
- Попробуйте перекалибровать координаты с помощью `calibrate.py`

### Бот не находит красный квадрат

- Убедитесь, что красный квадрат виден на миникарте
- Проверьте настройки цветов в `config.py` (HSV диапазоны)
- Убедитесь, что квадрат имеет черную оконтовку

### Бот движется не в ту сторону

- Проверьте настройку `MINIMAP_CENTER`
- Убедитесь, что стрелочка игрока правильно определяется
- Попробуйте изменить `TURN_THRESHOLD` в конфигурации

## Примечания

- Бот автоматически находит окно игры по названию (по умолчанию "RADMIR CRMP")
- Координаты миникарты указываются относительно окна игры, а не всего экрана
- Бот работает даже если окно игры перемещено или изменено в размере
- Рекомендуется использовать в оконном режиме для лучшей стабильности
- Бот автоматически останавливается при достижении цели или при отсутствии цели на миникарте

## Настройка названия окна игры

Если название окна игры отличается от "RADMIR CRMP", измените параметр `GAME_WINDOW_TITLE` в файле `config.py`:

```python
GAME_WINDOW_TITLE = "Ваше название окна"
```
