# TREASURE Casino - Telegram Web App

Современное казино приложение для Telegram с полным функционалом и PWA поддержкой.

## 🚀 Возможности

- **🎮 4 игры**: Dice, Wheel, Mines, Slots
- **💬 Чат**: Реальный чат между игроками через WebSocket
- **🔔 Уведомления**: Push уведомления через Telegram Web App
- **🎁 Бонусная система**: Ежедневные бонусы, промокоды, колесо фортуны
- **🏆 Рейтинги**: Таблицы лидеров и достижения
- **🎪 Турниры**: Регулярные турниры с призами
- **⚡ WebSocket**: Мгновенные обновления в реальном времени
- **📱 PWA**: Установка как приложение, офлайн режим
- **📊 Аналитика**: Отслеживание поведения пользователей
- **🌍 Локализация**: Полная поддержка русского языка

## 🛠 Требования

- Node.js 16+
- npm или yarn
- Laravel backend (для полного функционала)

## 🚀 Быстрый запуск

1. **Установка зависимостей:**
```bash
npm install
```

2. **Запуск в режиме разработки:**
```bash
npm run dev
```

3. **Сборка для продакшена:**
```bash
npm run build
```

## ⚙️ Конфигурация

### Переменные окружения

Скопируйте `env.example` в `.env` и настройте:

```env
# API Configuration
VITE_API_URL=http://localhost:8000/api

# WebSocket Configuration
VITE_WS_URL=ws://localhost:6001

# Development Configuration
VITE_APP_NAME=TREASURE Casino
VITE_APP_VERSION=1.0.0
```

## 🚀 Развертывание

1. Соберите приложение:
```bash
npm run build
```

2. Скопируйте содержимое папки `dist` на сервер

3. Настройте веб-сервер для обслуживания статических файлов

4. Убедитесь, что backend API доступен по настроенному URL

## 📞 Поддержка

При возникновении проблем:

1. Проверьте консоль браузера на ошибки
2. Убедитесь, что backend API работает
3. Проверьте конфигурацию WebSocket
4. Очистите кеш браузера и Service Worker
