# PersonPro

PersonPro - мобильное приложение, которое помогает пользователям стать лучшей версией себя через постановку целей, отслеживание прогресса и получение персонализированных рекомендаций от искусственного интеллекта.

## Особенности

- **Управление целями** - создавайте, редактируйте и отслеживайте свои цели в различных категориях
- **Трекинг задач** - разбивайте цели на конкретные задачи для достижения результатов
- **ИИ рекомендации** - получайте персонализированные рекомендации на основе вашей активности и целей
- **Аналитика прогресса** - визуализация ваших достижений и активности
- **Темная и светлая тема** - выбирайте комфортную для вас тему интерфейса
- **Модный дизайн** - современный UI с приятной анимацией и высокой эргономикой

## Технологии

- React Native / Expo
- TypeScript
- React Navigation
- AsyncStorage для локального хранения данных
- Контекст API для управления состоянием
- Интеграция с ИИ сервисами для рекомендаций

## Установка и запуск

1. Убедитесь, что у вас установлены Node.js и npm/yarn
2. Клонируйте репозиторий: `git clone https://github.com/yourusername/PersonPro.git`
3. Перейдите в директорию проекта: `cd PersonPro`
4. Установите зависимости: `npm install` или `yarn install`
5. Запустите проект:
   - iOS: `npm run ios` или `yarn ios`
   - Android: `npm run android` или `yarn android`
   - Web: `npm run web` или `yarn web`

## Структура проекта

```
src/
  ├── assets/         # Изображения, иконки и другие медиа-ресурсы
  ├── components/     # Многоразовые UI компоненты
  ├── context/        # Контекст приложения для управления состоянием
  ├── hooks/          # Пользовательские хуки
  ├── navigation/     # Настройка навигации
  ├── screens/        # Экраны приложения
  │   ├── auth/       # Экраны аутентификации
  │   └── main/       # Основные экраны приложения
  ├── services/       # Сервисы для работы с API и др.
  ├── types/          # TypeScript типы и интерфейсы
  └── utils/          # Вспомогательные функции и константы
```
